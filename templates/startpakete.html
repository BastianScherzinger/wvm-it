{% comment %} Schnellstart über dem Konfigurator (UX-Ausbau 2026-08). Warum es das gibt: Der Konfigurator zeigt über dreißig Positionen. Wer zum ersten Mal darauf schaut, weiß nicht, wo er anfangen soll — und genau dort brechen die meisten ab. Ein Klick setzt hier die Haken für einen typischen Bedarf; danach wird nur noch ergänzt oder weggenommen. Zwei Regeln: * **Kein Preis auf der Kachel.** Die Summe entsteht aus den gesetzten Haken und wird an genau einer Stelle angezeigt. Ein zweiter Preis auf der Kachel wäre eine zweite Preisquelle. * **Der Inhalt steht sichtbar drauf.** Ein Paket, dessen Zusammensetzung man erst nach dem Klick sieht, ist eine Wundertüte und kein Einstieg. Ohne JavaScript funktioniert es genauso: Die Kacheln sind Links auf ?paket=, und der Server setzt die Haken beim Rendern (views._paket_items). Parameter: `ziel` = Pfad, auf den die Kacheln ohne JavaScript verlinken. {% endcomment %}
